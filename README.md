# Разворачиватель адресов

Одностраничное веб-приложение для нормализации почтовых адресов: вставьте адрес в любом формате — получите готовый вариант в едином порядке.

Работает полностью локально в браузере, без интернета и установки. Всё приложение — один файл `index.html`.

## Возможности

- **Исходный адрес** — поле для вставки адреса из любого источника. Результат обновляется сразу при вводе.
- **Готовый адрес** — нормализованный вариант шрифтом Times New Roman, 14 пт.
- **Скопировать адрес** — отправляет готовый текст в буфер обмена.
- **Пример** — подставляет демонстрационный адрес для проверки.
- **Очистить** — сбрасывает оба поля.
- **Ошибка** — сохраняет текущую пару «исходный → готовый» в журнал ошибок, если результат получился неверным.
- **Просмотр ошибок** — журнал всех отмеченных ошибок с кнопками:
  - **Выгрузить в файл** — сохраняет журнал в `ошибки_разворота_адреса.csv` (открывается в Excel);
  - **Удалить все ошибки** — очистка журнала;
  - удаление записей по одной.
- **Инструкция** — описание каждой функции приложения.
- **Правила исправления** — перечень правил, по которым преобразуется адрес.

Ошибки хранятся в браузере (localStorage) и не пропадают после закрытия страницы. Список привязан к браузеру и компьютеру: в другом браузере журнал будет пустым.

## Правила преобразования

Приложение пересобирает адрес в строгом порядке:

1. **Тип улицы** (`ул.`, `пр-кт.`, `пер.`, `пл.`, `шоссе` и т. д.) — всегда в начале, с точкой (у «шоссе» точки нет).
2. **Название улицы** — после типа.
3. **Дом** — `д. 45`, вместе с корпусами и строениями (`корп. 2`, `стр. 1`).
4. **Населённый пункт** — `г.`, `пгт`, `с.`, `рп` и т. д.
5. **Регион** — республика, край, область (кроме городов федерального значения).
6. **Индекс** — всегда последним, 6 цифр.
