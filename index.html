Инструкция по функциям приложения

Вкладки. «Одиночный адрес» — один адрес, «Пакет адресов» — вставка столбца из Excel.

Поле «Исходный адрес». Вставляйте адрес в любом виде — с лишними запятыми, пробелами, словом «Россия», сокращениями или в развёрнутом виде. Готовый адрес пересчитывается автоматически, кнопку нажимать не нужно.

Поле «Готовый адрес». Нормализованный адрес, шрифт — Times New Roman, 14 пт.

Скопировать адрес — помещает готовый адрес в буфер обмена. Кнопка зеленеет на секунду — копирование прошло.

Пример — подставляет демонстрационную строку, чтобы посмотреть, как работает преобразование. Очистить — стирает оба поля.

Ошибка — сохраняет пару «исходный → готовый» в список ошибок. Данные хранятся в браузере и не пропадают после закрытия страницы.

Просмотр ошибок — таблица из трёх колонок: «Было» (исходный адрес), «Стало» (что выдало приложение), «Как надо» (правильный вариант). В поле «Как надо» при добавлении записи уже подставлен отформатированный адрес — исправьте его поверх. Изменения сохраняются сами. Крестик в строке убирает запись из списка.

Выгрузить ошибки в файл — сохраняет список в errors.csv: колонки «Режим», «Исходный адрес», «Готовый адрес», «Как должно быть». Файл открывается в Excel. Список после выгрузки не очищается.

Пакет адресов. Вставьте столбец из Excel в поле (каждая строка — отдельный адрес) и нажмите «Обработать». Появится таблица: исходный адрес, отформатированный, кнопки «Копировать» и «Ошибка» для каждой строки. Строки с отмеченной ошибкой подсвечиваются. Если во вставленном тексте есть табуляция, ячейки склеятся пробелом.

Выгрузить весь пакет — сохраняет все обработанные адреса: №, исходный, отформатированный, «как должно быть» и отметку об ошибке.

Инструкция / Правила исправления — эта справка и перечень правил преобразования. Если адрес обработан вопреки правилам — жмите «Ошибка».

Правила исправления адреса

  • Порядок сборки: тип улицы, название улицы, дом, корпус/строение, квартира, населённые пункты, район, область/республика, индекс.
  • Слова «Россия», «РФ», «Российская Федерация» удаляются в любой позиции адреса.
  • Лишние символы: двойные и неразрывные пробелы, переводы строк, табуляции, « ,», «,,», запятые в начале и конце строки убираются.
  • Полные слова приводятся к сокращениям: «город» → «г.», «улица» → «ул.», «проспект» → «пр-кт.», «переулок» → «пер.», «деревня» → «д.», «село» → «с.», «посёлок» → «п.», «дом» → «д.», «квартира» → «кв.», «корпус» → «корп.».
  • Тип улицы всегда в начале: «Космонавтов пр-кт» → «пр-кт. Космонавтов», «площадь Красной Армии» → «пл. Красной Армии». «ш» → «шоссе» и «б-р» — без точки: «шоссе Саввинское», «б-р Английский». «проезд» → «пр.»: «2-й Луговой проезд» → «пр. 2-й Луговой».
  • Дом: «д.12а» → «д. 12А» (буква заглавная), «д. 5» остаётся. «корп.» и «кв.» ставятся рядом с домом через запятую: «д. 3, корп.3, кв.200». Значения «кв.Нет» и «кв.нет» удаляются из адреса.
  • Населённые пункты — тип перед названием: «Балашиха г» → «г. Балашиха», «Ржавки рп» → «рп. Ржавки», «Михайловка д» → «д. Михайловка», «Кагальницкая ст-ца» → «ст-ца. Кагальницкая». Посёлок, село, деревня, рп, ст-ца ставятся перед домом, если улицы в адресе нет, и после блока дома при наличии улицы. Город всегда после блока дома.
  • Города федерального значения (Москва, Санкт-Петербург, Севастополь) выводятся без «г.».
  • Республика: «Мордовия Респ» → «Респ. Мордовия». Район: «Ковылкинский р-н» → «р-н. Ковылкинский». Область: «Московская обл» → «Московская обл.».
  • Индекс — 6 цифр — всегда ставится последним, где бы он ни стоял в исходной строке.
  • Уже правильный адрес остаётся без изменений: если структура «ул. X, д. N, г. Y, регион, индекс» уже соблюдена, приложение ничего не переставляет.
  • Если часть адреса распознать не удалось, адрес возвращается очищенным, но без перестановки частей — такие случаи стоит отмечать кнопкой «Ошибка».
